Ground GNSS, survey, construction & mapping clients

Emlid, Trimble, Leica, Topcon, Spectra, Carlson, CHC, South, and most software that has an “NTRIP caster” or “CORS” profile.

  1. Add a new NTRIP caster / network profile (wording varies by brand).
  2. Address / host: rtk.asap-nj.com — if the name fails, use 67.205.128.14.
  3. Port: 2101
  4. Mount point / mount: ASAP-NJ
  5. Username & password: from your ASAP NJ signup
  6. Protocol: NTRIP (v1 is fine). Corrections: RTCM 3.x from our fixed base.
  7. Connect and confirm stream age / status is live before you survey or stake.
  8. Need internet on the rover or controller (cellular, hotspot, or field modem)—same as any cloud caster.
Brand-agnostic: If the device asks for host, port, mount, user, and password, you’re set. We are not locked to one manufacturer.

DJI aircraft — Pilot 2 Custom Network RTK

One supported path among many—not the only use of this stream. Matrice / Mavic RTK models with Custom Network RTK.

  1. Power on RC + aircraft. Open DJI Pilot 2.
  2. Confirm the RC has internet (cellular, hotspot, or Wi‑Fi with data path).
  3. Camera view → RTK (or Settings → RTK).
  4. RTK Positioning ON → Service Type → Custom Network RTK.
  5. Enter:
    Hostrtk.asap-nj.com
    If DNS fails67.205.128.14
    Port2101
    User / passwordfrom your ASAP NJ signup
    Mount pointASAP-NJ
  6. Save / connect. Wait for FIX.
Note: Custom Network RTK uses the controller’s network path. No internet on the RC = no FIX.

Other RTK aircraft / non-DJI NTRIP

  1. Open your flight app’s RTK / NTRIP / CORS settings (labels vary by brand).
  2. Choose custom / network / NTRIP caster—not a closed manufacturer-only network if you want ASAP-NJ.
  3. Same fields: host rtk.asap-nj.com, port 2101, mount ASAP-NJ, your unique user/pass.
  4. If the app says “Server” instead of “Host,” use the same value.
  5. Confirm the aircraft or controller has a working internet path before expecting FIX.

Still stuck?

  • Timeout / can’t connect: try public IP 67.205.128.14 instead of the name; confirm the rover/controller has working internet.
  • Connects, no FIX: sky view, distance from base, or base momentarily offline — wait / recheck with us.
